# WordPress を少し便利にするプラグイン「OD Chotto Benri」を作りました

WordPress を使っていると、「ここに、この小さな機能だけあったら便利なのに」と感じる場面があります。

そのたびに別々のプラグインを作ったり、テーマの `functions.php` へ処理を追加したりする方法もあります。ただ、小さな処理がいろいろな場所へ散らばってしまうと、あとから見返したときに管理しにくくなります。テーマを変更する際に、必要なコードを移し忘れてしまう可能性もあります。

そこで、自分で使いたい小さな機能を少しずつまとめていくために「OD Chotto Benri」という WordPress プラグインを作りました。

この記事では、OD Chotto Benri がどのようなプラグインなのか、現在利用できる機能と使い方を紹介します。

> この記事は OD Chotto Benri 0.2.0 をもとに書いています。今後、機能の追加に合わせて内容も更新していく予定です。

## OD Chotto Benri とは

OD Chotto Benri は、WordPress を使ううえで個人的に欲しい「ちょっと便利」な機能を、ひとつにまとめていくプラグインです。

大きなひとつの機能を提供するというよりも、小さく独立した機能を必要に応じて追加していくことを目的にしています。プラグインを有効化すると、WordPress 管理画面の「設定」に「OD Chotto Benri」が追加され、利用する機能をチェックボックスで選択できます。

現時点での主な特徴は、次のとおりです。

- 小さな機能をひとつのプラグインで管理できる
- 利用する機能を管理画面から個別に切り替えられる
- 通常の WordPress の操作やブロックになるべく馴染む形で利用できる
- GitHub Releases を通じて更新版を受け取れる

機能をまとめてはいますが、すべてを常に使わなければならないわけではありません。サイトごとに必要な機能だけを選べるところを大切にしています。

## OD Chotto Benri をインストールする

OD Chotto Benri は、GitHub のリポジトリで管理しています。

1. [OD Chotto Benri の Releases ページ](https://github.com/Olein-jp/od-chotto-benri/releases)から配布用の `od-chotto-benri.zip` をダウンロードする
2. WordPress 管理画面で「プラグイン」→「新規プラグインを追加」を開く
3. 「プラグインのアップロード」から、ダウンロードした ZIP ファイルを選ぶ
4. 「今すぐインストール」を選び、インストール後にプラグインを有効化する

プラグインの動作要件は、WordPress 6.5以上、PHP 7.4以上です。インストールする前に、お使いのサーバー環境も確認しておくと安心です。

新しいバージョンが公開された場合は、通常のプラグインと同じように WordPress 管理画面の「プラグイン」から更新できます。

## 利用する機能を設定する

プラグインを有効化したら、WordPress 管理画面の「設定」→「OD Chotto Benri」を開きます。

「利用する機能」に、現在利用できる機能が一覧で表示されます。使いたい機能にチェックを入れ、不要な機能はチェックを外して「変更を保存」を選択してください。

初めて利用するときは、すべての機能が有効になります。また、プラグインの更新によって新しい機能が追加された場合も、その機能は初期状態で有効になります。更新後は一度設定画面を開き、追加された機能を使うか確認しておくと良いでしょう。

### 条件付き更新日

「条件付き更新日」は、記事の投稿日と更新日の日付が異なる場合だけ、更新日を表示する機能です。

#### この機能でできること

WordPress には、記事を最初に公開した「投稿日」と、最後に保存した「更新日」があります。しかし、公開した当日に文章を少し直しただけでも更新日時は変わります。そのような場合に投稿日と更新日を並べて表示すると、同じ日付が重複して見えることがあります。

条件付き更新日を使うと、投稿日と更新日が同じ日付の場合は更新日のまとまりを表示しません。別の日に記事を更新した場合だけ、「更新：」というラベルと更新日が表示されます。

たとえば、次のような表示を作れます。

```text
公開：2026年8月1日
更新：2026年8月7日
```

記事を公開した日から更新されていない場合は、2行目の更新日が出力されません。読者にとって意味のあるときだけ更新日を見せたい場合に使いやすい機能です。

#### 機能の使い方

この機能を有効にすると、ブロックエディターのブロック挿入ツールに「条件付き更新日」が追加されます。これは「ブロックバリエーション」と呼ばれる仕組みを使っています。ブロックバリエーションとは、既存のブロックへあらかじめ設定や内容を組み合わせ、別の用途のブロックとして選べるようにする仕組みです。

「条件付き更新日」は、WordPress のグループブロックをもとにしています。ブロックの中には、最初から次の要素が入っています。

- 「更新：」という段落
- 更新日時を表示する「投稿日時」ブロック

ブロックテーマを利用している場合は、「外観」→「エディター」から個別投稿テンプレートを開き、投稿日を表示している付近に「条件付き更新日」を追加する使い方が分かりやすいと思います。ブロックを追加したあとは、文字サイズ、余白、色などをサイトのデザインに合わせて調整してください。

投稿や固定ページの本文へ追加することもできますが、すべての記事で共通して表示したい場合は、記事ごとに入れるよりも個別投稿テンプレートへ配置したほうが管理しやすいでしょう。

#### この機能について知っておきたいこと

条件付き更新日は、投稿日と更新日の「年月日」を比較しています。時刻が異なっていても、同じ日であれば更新日は表示されません。

また、表示の切り替えは「条件付き更新日」として追加したグループブロックだけに適用されます。すでにサイト内で使っている通常のグループブロックには影響しません。

この機能は、更新日そのものを書き換えるものではありません。WordPress に記録されている更新日を使い、表示するかどうかだけを判断します。そのため、記事を保存したタイミングによっては、文章を大きく変更していなくても更新日が変わる場合があります。

なお、現在の機能はブロックとして提供しています。クラシックテーマの PHP テンプレートへ自動的に更新日を挿入する機能や、ショートコードは用意していません。利用しているテーマの構成によっては、別の実装方法を検討する必要があります。

## このプラグインが向いているケース

OD Chotto Benri は、次のような方に使いやすいプラグインだと考えています。

- 現在用意されている機能が、自分のサイトの運用に合っている
- テーマへ直接コードを追加せず、小さな機能をプラグインとして管理したい
- 必要な機能だけを管理画面で選びたい
- GitHub で配布されるプラグインを自分でインストールし、更新できる

一方で、ひとつの目的に特化した多機能なプラグインを探している場合や、WordPress.org のプラグインディレクトリからだけインストールしたい場合は、別のプラグインのほうが合うかもしれません。

また、このプラグインは僕が自分で使いたい機能をまとめていくところから始めています。すべての WordPress サイトに必要な機能を網羅するものではありません。機能の内容と注意点を確認したうえで、運用中のサイトに合うものだけを利用してください。

## 今後も小さな機能を追加していきます

OD Chotto Benri には、今後も WordPress を使うなかで欲しいと感じた機能を追加していく予定です。

機能が増えても、設定画面から使うものだけを選べる基本的な考え方は変えないつもりです。「便利そうだから全部入れる」のではなく、サイトごとに必要なものだけを選び、無理なく管理できる形を目指しています。

新しい機能を追加したときは、この記事にも使い方や注意点を追記していきます。気になる機能があれば、ぜひ試してみてください。
